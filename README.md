# TravelDeal Finder - Multilingual PWA

A trilingual (English, Italian, Persian) Progressive Web App for finding hotel deals.

## Features

- 🌍 Trilingual: English, Italian, Persian
- 💰 Price comparison across platforms
- 📱 PWA - install on any device
- 💵 Built-in affiliate monetization


## Files

- `index.html` - Main app
- `manifest.json` - PWA config
- `service-worker.js` - Offline support
- `css/style.css` - Styles
- `js/i18n.js` - Languages
- `js/app.js` - Main logic
- `js/hotel-search.js` - Affiliate integration
